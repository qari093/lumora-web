# Lumora Native FYP Doctrine

## Locked rule
Main FYP is native-video only.

## YouTube role
YouTube is allowed only for:
- discovery
- trend intelligence
- trailer cards outside main FYP
- Discover tab

YouTube iframe is prohibited inside the core native FYP.

## Low-cost playback doctrine
- MP4 first
- HLS later only when needed
- no expensive ghost loops
- no heavy AI at launch
- 3-card virtual swiper
- one active video player only
