# ZenWallet Global Compliance Matrix

## Region groups
- EU/EEA/UK
- North America
- LATAM
- Africa
- India/South Asia
- Southeast Asia
- Middle East
- Unsupported/Manual

## Required controls
- Transparent EUR base charge
- Local FX estimate disclaimer
- DCC warning
- PSP origin recorded
- Tax basis recorded
- Refund eligibility visible
- Chargeback support path visible
- Data export support
- Deletion request handling where legally permitted
- Audit retention for ledger integrity

## Unsupported payment regions
If no PSP is available, Pay Later invoice mode is the fallback.

## Creator payouts
Creator payout availability is country-specific and never implied unless active.
