# LCE-X+ Culture-Aware Surfacing Rule

Status: LOCKED
Step Lock: 053/375

## Core Principle
Discovery must respect cultural context before amplification.

## Product Rule
Cultural confidence directly influences visibility.

## Hard Rules
- High cultural confidence allows full promotion.
- Medium confidence allows controlled promotion.
- Low confidence requires downgrade to metadata-only or deprioritization.
- Restricted confidence requires manual review or suppression.
- Regional context must override global assumptions.

## Safety Layer
- Cultural escalation rules must always be evaluated before ranking.
- Region-language overlays must be respected.
- Sensitive or ambiguous content must never auto-scale globally.

## Experience Goal
Users should feel relevance without cultural friction or misplacement.
