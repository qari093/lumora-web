# LCE-X+ Predictive-Not-Reactive Discovery Doctrine

Status: LOCKED
Step Lock: 052/375

## Core Doctrine
LCE-X+ should not wait for full mainstream saturation.
It should identify early directional momentum before broad-market obviousness.

## Product Rule
Prediction is part of discovery quality.

## Hard Rules
- Early-signal convergence outranks late raw volume.
- Search, conversation, fandom, and entity spikes must be interpreted together.
- The feed should reward credible emergence, not only already-maxed popularity.
- Prediction must remain confidence-weighted, not hype-weighted.
- False certainty is forbidden; uncertainty must downgrade promotion.

## Experience Goal
Users should feel that Lumora helps them see what is next, not only what is already everywhere.
