# LCE-X+ Metadata Fallback Doctrine

Status: LOCKED
Step Lock: 005/375

## Core Rule
If teaser media is unavailable, blocked, removed, degraded, or rights-uncertain, discovery must continue through metadata-safe presentation.

## Approved Fallback Order
1. Official teaser media
2. Safe poster / artwork card
3. Title + release + context card
4. Watchlist / reminder / discussion CTA card
5. Trend-only signal card

## Hard Requirements
- No dead cards.
- No broken media shells.
- No blank feed slots.
- Metadata fallback must preserve relevance, trust, and context.
- Fallback selection must respect rights, region, age, and source confidence.

## Product Rule
Loss of media is not loss of discovery.
