# LCE-X+ Official Source Trust Hierarchy

Status: LOCKED
Step Lock: 004/375

## Trust Order (Highest → Lowest)
1. Official studio / label / publisher / platform source
2. Official verified talent / franchise / game account
3. Approved partner / distributor / event organizer
4. Trusted editorial / press source
5. Community signal source (never primary truth source)
6. Unverified source (never eligible for direct trust)

## Hard Rules
- Official sources always outrank non-official sources by default.
- Unverified sources can contribute weak signals only, never primary truth.
- A lower-trust source cannot override a higher-trust source without explicit ops review.
- If source confidence is unclear, downgrade to metadata-only or suppress.

## Product Rule
Trust is a ranking input and a display permission input.
