# LCE-X+ Teaser-First Positioning

Status: LOCKED
Step Lock: 003/375

## Core Positioning
Lumora is NOT a content library.
Lumora is a discovery engine for what is about to matter.

## Teaser-First Rule
- Teasers are primary units of discovery
- Full content is NOT required for feed relevance
- Discovery must work even with metadata-only inputs

## Experience Principle
- Users should feel “ahead of the world”
- Feed must surface emerging signals, not only trending ones
- Every card must answer: “Why is this becoming important?”

## Content Hierarchy
1. Official Teasers
2. Verified Media
3. Metadata Fallback
4. Trend Signals

## Non-Negotiable
No empty feed. No dead cards. No dependency on full media availability.
