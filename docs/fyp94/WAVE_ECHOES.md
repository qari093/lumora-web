# Lumora FYP 9.4 Wave Echoes

Wave Echoes are private memory artifacts of participation.

Rules:
- Created only when user participates in a wave.
- Contain a small poster set (max 3).
- Expire after a fixed window.
- Missed waves appear as empty slots.
- Lifetime can extend via streak continuity.
- No sharing, no public feed, no competition.
