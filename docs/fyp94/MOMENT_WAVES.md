# Lumora FYP 9.4 Moment Waves

Moment Waves are short live-feeling bursts created from high-ThrillScore category clusters.

Rules:
- Trigger only when enough high-score clips exist.
- Default duration is 30–60 minutes.
- Add “happening now” metadata.
- Track anonymous participation only.
- After the wave, clips return to the normal pool.
- No permanent loss or hard lockout.
